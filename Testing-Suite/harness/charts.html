E-Voting — Distributed vs Single-Node Performance

60 votes per data point, 2 repetitions, fresh-seeded each point. Error bars = std dev across reps. 720 votes total, 0 errors, 0 double-votes.

Takeaway: single-node is faster at low load (no queue overhead) but saturates as concurrency rises; the distributed queue-based architecture scales up — ~2.2× throughput and ~2.6× lower p95 latency at concurrency 50.
